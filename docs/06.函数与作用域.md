# Python 函数与作用域

函数是 Python 中组织代码最常用的方式。把一段完成单一任务的代码放进函数后，我们可以重复调用它、给它传入不同数据，也可以更容易地测试和维护程序。

作用域则回答一个重要问题：**一个变量在哪里可以被访问？** 理解函数和作用域，能帮助你读懂绝大多数 Python 程序，也能避免“变量找不到”“变量被意外修改”等常见错误。

## 一、学习目标

学完本文，你应该能够：

- 定义和调用函数。
- 使用参数、返回值、默认参数和关键字参数。
- 理解局部变量、全局变量和 LEGB 查找规则。
- 正确使用 `global` 和 `nonlocal`。
- 识别可变默认参数、变量遮蔽等常见问题。
- 使用类型标注、文档字符串和测试写出更清晰的函数。

## 二、为什么要使用函数

假设程序中多次需要计算长方形面积。如果不使用函数，代码可能会重复出现：

```python
length = 10
width = 5
area = length * width
print(area)

length = 8
width = 3
area = length * width
print(area)
```

使用函数后，可以把“计算面积”这个动作抽出来：

```python
def rectangle_area(length, width):
    return length * width


print(rectangle_area(10, 5))  # 50
print(rectangle_area(8, 3))   # 24
```

函数带来的好处：

1. **复用**：同一段逻辑只写一次。
2. **分工**：每个函数负责一个清晰的任务。
3. **易测试**：可以单独检查函数是否正确。
4. **易修改**：修改函数内部逻辑，不必到处寻找重复代码。

## 三、定义和调用函数

### 3.1 基本语法

```python
def 函数名(参数1, 参数2):
    """函数说明（可选）"""
    函数体
    return 返回值
```

关键字说明：

- `def`：告诉 Python 下面要定义一个函数。
- 函数名：建议使用小写字母和下划线，例如 `calculate_total`。
- 参数：函数接收的数据，可以没有参数。
- 函数体：必须缩进，通常使用 4 个空格。
- `return`：结束函数并把结果交给调用者，可以省略。

### 3.2 定义不等于执行

```python
def say_hello():
    print("你好，Python！")

# 定义函数时不会打印内容
say_hello()  # 调用后才会打印
```

函数名后面的圆括号表示“调用”。忘记圆括号时，得到的是函数对象，而不是函数运行结果：

```python
print(say_hello)    # 类似 <function say_hello at 0x...>
print(say_hello())  # 你好，Python！
```

### 3.3 没有 `return` 时返回什么

如果函数没有写 `return`，或者只写了 `return` 没有值，Python 会返回 `None`：

```python
def print_message(message):
    print(message)


result = print_message("学习函数")
print(result)  # None
```

要区分：`print()` 是把内容显示到屏幕，`return` 是把结果交给调用者。

```python
def add(a, b):
    return a + b


total = add(2, 3)  # total 得到 5
```

## 四、参数与传参

### 4.1 位置参数

按照参数出现的顺序传值：

```python
def introduce(name, age):
    print(f"我叫{name}，今年{age}岁")


introduce("小明", 18)
```

位置顺序写错，结果也会错：

```python
introduce(18, "小明")  # 语法上可运行，但含义不正确
```

### 4.2 关键字参数

明确写出参数名，顺序可以调整：

```python
introduce(age=18, name="小明")
```

位置参数和关键字参数可以混用，但位置参数必须写在关键字参数前面：

```python
introduce("小明", age=18)  # 正确
# introduce(name="小明", 18)  # SyntaxError，错误
```

### 4.3 默认参数

定义函数时给参数一个默认值。调用时不传该参数，就使用默认值：

```python
def greet(name, message="欢迎学习 Python"):
    return f"{name}，{message}！"


print(greet("小明"))              # 小明，欢迎学习 Python！
print(greet("小明", "早上好"))     # 小明，早上好！
```

带默认值的参数必须放在没有默认值的参数后面：

```python
# def greet(message="你好", name):  # SyntaxError
#     pass
```

### 4.4 参数传递的是对象引用

Python 函数接收的是对象的引用。对不可变对象（如整数、字符串）重新赋值，通常不会影响函数外的变量；对可变对象（如列表、字典）进行原地修改，则可能影响外部对象：

```python
def change_number(number):
    number = 100


def append_item(items):
    items.append("新项目")


number = 1
change_number(number)
print(number)  # 1，函数内只是让局部变量指向了新对象

items = ["原项目"]
append_item(items)
print(items)  # ['原项目', '新项目']，列表被原地修改
```

如果不希望函数修改传入的列表，可以先复制：

```python
def add_item_without_change(items, item):
    new_items = items.copy()
    new_items.append(item)
    return new_items
```

## 五、返回值

### 5.1 返回一个值

```python
def square(number):
    return number * number


result = square(4)
print(result)  # 16
```

### 5.2 返回多个值

Python 实际上会把多个返回值打包成一个元组：

```python
def divide_with_remainder(dividend, divisor):
    quotient = dividend // divisor
    remainder = dividend % divisor
    return quotient, remainder


quotient, remainder = divide_with_remainder(17, 5)
print(quotient)   # 3
print(remainder)  # 2
```

### 5.3 提前结束函数

执行到 `return` 后，函数立即结束，后面的代码不会执行：

```python
def check_age(age):
    if age < 0:
        return "年龄不能为负数"
    if age >= 18:
        return "已成年"
    return "未成年"
```

## 六、参数进阶

### 6.1 任意数量的位置参数：`*args`

`*args` 会把多余的位置参数收集成一个元组：

```python
def sum_all(*numbers):
    return sum(numbers)


print(sum_all(1, 2, 3))       # 6
print(sum_all(10, 20, 30, 40))  # 100
```

`args` 只是一个普通名称，真正有特殊作用的是前面的 `*`。

### 6.2 任意数量的关键字参数：`**kwargs`

`**kwargs` 会把多余的关键字参数收集成一个字典：

```python
def show_profile(**profile):
    for key, value in profile.items():
        print(f"{key}: {value}")


show_profile(name="小明", age=18, city="杭州")
```

### 6.3 组合使用

常见顺序是：普通参数、`*args`、关键字参数、`**kwargs`：

```python
def demo(required, *args, option=True, **kwargs):
    print(required, args, option, kwargs)


demo("必须值", 1, 2, option=False, color="blue")
# 必须值 (1, 2) False {'color': 'blue'}
```

### 6.4 仅限关键字参数

在参数列表中使用单独的 `*`，后面的参数必须用参数名传入：

```python
def connect(host, *, port=80, timeout=5):
    return f"{host}:{port}, timeout={timeout}"


connect("example.com", port=443, timeout=10)  # 正确
# connect("example.com", 443, 10)  # TypeError
```

这样可以避免调用者忘记参数含义，也方便以后增加参数。

### 6.5 解包传参

使用 `*` 可以把列表或元组拆成位置参数，使用 `**` 可以把字典拆成关键字参数：

```python
def rectangle_area(length, width):
    return length * width


dimensions = (10, 5)
print(rectangle_area(*dimensions))

options = {"length": 8, "width": 3}
print(rectangle_area(**options))
```

## 七、作用域与 LEGB 规则

作用域（scope）是变量可以被访问的范围。Python 查找变量时，遵循 **LEGB** 顺序：

| 顺序 | 名称      | 含义                               |
| ---- | --------- | ---------------------------------- |
| L    | Local     | 当前函数内部的局部作用域           |
| E    | Enclosing | 外层函数的作用域（嵌套函数时存在） |
| G    | Global    | 当前模块文件的全局作用域           |
| B    | Built-in  | Python 内置名称，如 `len`、`print` |

查找变量时从 L 开始，找不到再向外查找；找到后停止。下面的例子中，函数优先使用局部变量：

```python
name = "全局的小明"


def show_name():
    name = "局部的小红"
    print(name)


show_name()     # 局部的小红
print(name)     # 全局的小明
```

### 7.1 局部作用域

函数内部创建的变量，默认只能在函数内部使用：

```python
def calculate():
    result = 10 + 20
    return result


print(calculate())
# print(result)  # NameError，函数外不存在 result
```

函数调用结束后，局部变量通常也就不能再直接访问了。

### 7.2 全局作用域

在函数外定义的变量属于模块级全局作用域，同一文件中的函数可以读取它：

```python
tax_rate = 0.13


def add_tax(price):
    return price * (1 + tax_rate)


print(add_tax(100))
```

但大型程序不应大量依赖可变的全局变量，因为函数行为会受到外部状态影响，测试和维护都更困难。更推荐通过参数传入：

```python
def add_tax(price, tax_rate):
    return price * (1 + tax_rate)
```

### 7.3 函数内赋值会创建局部变量

只要函数内部出现对某个名称的赋值，Python 默认就把它当作局部变量。这可能导致 `UnboundLocalError`：

```python
count = 10


def increase():
    # count += 1 等价于 count = count + 1
    # Python 会认为 count 是局部变量，但读取时它还没有值
    # count += 1  # UnboundLocalError
    pass
```

### 7.4 使用 `global` 修改全局变量

如果确实需要在函数内重新绑定全局变量，使用 `global` 声明：

```python
count = 0


def increase():
    global count
    count += 1


increase()
print(count)  # 1
```

初学阶段建议把 `global` 当作“需要谨慎使用的工具”。很多时候，返回新值会更清晰：

```python
def increase(count):
    return count + 1


count = increase(count)
```

## 八、嵌套函数与 `nonlocal`

函数可以定义在另一个函数内部。内层函数可以读取外层函数的变量：

```python
def make_greeter(prefix):
    def greet(name):
        return f"{prefix}，{name}！"

    return greet


hello = make_greeter("你好")
print(hello("小明"))  # 你好，小明！
```

这里的 `greet` 记住了外层的 `prefix`，这种现象叫**闭包（closure）**。

如果内层函数要修改外层函数的变量，需要使用 `nonlocal`：

```python
def make_counter():
    count = 0

    def next_count():
        nonlocal count
        count += 1
        return count

    return next_count


counter = make_counter()
print(counter())  # 1
print(counter())  # 2
```

`nonlocal` 只适用于嵌套函数中的外层局部变量，不能用来修改模块全局变量。

## 九、默认参数的常见陷阱

不要把可变对象（列表、字典、集合）直接作为默认参数：

```python
# 不推荐
def add_name(name, names=[]):
    names.append(name)
    return names


print(add_name("小明"))  # ['小明']
print(add_name("小红"))  # ['小明', '小红']，结果会保留上一次调用的数据
```

原因是：默认参数只在函数定义时创建一次，而不是每次调用时创建。

正确写法是使用 `None`，在函数内部创建新列表：

```python
def add_name(name, names=None):
    if names is None:
        names = []
    names.append(name)
    return names


print(add_name("小明"))  # ['小明']
print(add_name("小红"))  # ['小红']
```

## 十、类型标注与文档字符串

类型标注不会自动阻止错误输入，但能帮助人和工具理解函数的接口：

```python
def calculate_discount(price: float, rate: float = 0.1) -> float:
    """计算折扣后的价格。

    Args:
        price: 原价，必须大于等于 0。
        rate: 折扣比例，例如 0.1 表示打九折。

    Returns:
        折扣后的价格。
    """
    if price < 0 or not 0 <= rate <= 1:
        raise ValueError("price 或 rate 不合法")
    return price * (1 - rate)
```

好的函数通常具备以下特点：

- 函数名能说明动作，例如 `load_config`、`format_price`。
- 一个函数尽量只完成一个主要任务。
- 参数和返回值含义清楚。
- 对非法输入给出明确错误。
- 不依赖不必要的全局状态。

## 十一、函数也是对象

在 Python 中，函数可以保存到变量、放入列表，也可以作为参数传给另一个函数：

```python
def double(number):
    return number * 2


operation = double
print(operation(5))  # 10

numbers = [1, 2, 3]
result = list(map(double, numbers))
print(result)  # [2, 4, 6]
```

把函数作为参数的函数，称为高阶函数。初学时先掌握普通函数，之后再逐步学习 `map`、`filter`、装饰器等用法。

## 十二、递归函数简介

函数调用自身，叫递归。递归必须有明确的结束条件：

```python
def countdown(number):
    if number <= 0:  # 结束条件
        print("出发！")
        return
    print(number)
    countdown(number - 1)


countdown(3)
# 3
# 2
# 1
# 出发！
```

递归适合处理树、目录等嵌套结构，但简单的重复任务通常用循环更直观。忘记结束条件会导致 `RecursionError`。

## 十三、常见错误与排查方法

### 13.1 忘记调用函数

```python
result = add       # result 是函数对象
result = add(1, 2) # result 才是计算结果
```

### 13.2 参数数量不匹配

```python
def add(a, b):
    return a + b


# add(1)       # TypeError：缺少参数
# add(1, 2, 3) # TypeError：参数过多
```

### 13.3 局部变量越界

```python
def create_message():
    message = "你好"
    return message


# print(message)  # NameError
```

解决方法通常是：通过 `return` 返回，或把需要的数据作为参数传入。

### 13.4 把 `print` 当成 `return`

```python
def wrong_add(a, b):
    print(a + b)


result = wrong_add(1, 2)  # 屏幕显示 3，但 result 是 None
```

如果调用者还需要使用结果，应写 `return a + b`。

### 13.5 变量遮蔽（shadowing）

不要用内置名称作为变量名，否则可能覆盖内置函数：

```python
# 不推荐
list = [1, 2, 3]
# list("abc")  # TypeError，因为 list 已经被列表变量覆盖
```

常见需要避开的名称包括 `list`、`str`、`sum`、`max`、`id`、`input` 等。

## 十四、练习题

### 练习 1：温度转换

编写 `celsius_to_fahrenheit(celsius)`，把摄氏温度转换为华氏温度，公式为 `华氏 = 摄氏 * 9 / 5 + 32`。

参考答案：

```python
def celsius_to_fahrenheit(celsius: float) -> float:
    return celsius * 9 / 5 + 32


print(celsius_to_fahrenheit(0))   # 32.0
print(celsius_to_fahrenheit(100)) # 212.0
```

### 练习 2：统计成绩

编写函数，接收任意数量的成绩，返回最高分、最低分和平均分。

参考答案：

```python
def score_summary(*scores):
    if not scores:
        raise ValueError("至少提供一个成绩")
    return max(scores), min(scores), sum(scores) / len(scores)


print(score_summary(80, 90, 70))  # (90, 70, 80.0)
```

### 练习 3：理解作用域

运行下面代码，并预测输出：

```python
message = "外层"


def outer():
    message = "中层"

    def inner():
        print(message)

    inner()


outer()
print(message)
```

答案是先输出 `中层`，再输出 `外层`。内层函数按照 LEGB 规则，在外层函数作用域中找到了 `message`。

## 十五、总结速查表

| 需求             | 写法                                  |
| ---------------- | ------------------------------------- |
| 定义函数         | `def func(...):`                      |
| 调用函数         | `func(...)`                           |
| 返回结果         | `return value`                        |
| 默认参数         | `def func(x=default):`                |
| 任意位置参数     | `def func(*args):`                    |
| 任意关键字参数   | `def func(**kwargs):`                 |
| 读取全局变量     | 函数内可直接读取                      |
| 修改全局变量     | `global name`（谨慎使用）             |
| 读取外层函数变量 | 直接读取                              |
| 修改外层函数变量 | `nonlocal name`                       |
| 作用域查找顺序   | Local → Enclosing → Global → Built-in |
| 避免可变默认参数 | 用 `None`，在函数内创建对象           |

学习函数时，可以始终问自己三个问题：

1. 这个函数接收什么参数？
2. 它返回什么结果？
3. 它读取或修改了哪些作用域中的变量？

能清楚回答这三个问题，就已经掌握了函数和作用域的核心。
