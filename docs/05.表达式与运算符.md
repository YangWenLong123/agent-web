## 赋值运算符

赋值运算符用于把数据保存到变量中。

```python
age = 18
```

这里的`=`表示把右边的值赋给左边的变量，不是`等于`

### 复合赋值

| 运算符 | 示例      | 等价写法     |
| ------ | --------- | ------------ |
| `+=`   | `x += 2`  | `x = x + 2`  |
| `-=`   | `x -= 2`  | `x = x - 2`  |
| `*=`   | `x *= 2`  | `x = x * 2`  |
| `/=`   | `x /= 2`  | `x = x / 2`  |
| `//=`  | `x //= 2` | `x = x // 2` |
| `%=`   | `x %= 2`  | `x = x % 2`  |
| `**=`  | `x **= 2` | `x = x ** 2` |

## 比较运算符

比较运算符用于比较两个数据，结果通常是布尔值`True`或者`False`。

| 运算符 | 作用       | 示例           |
| ------ | ---------- | -------------- |
| `==`   | 等于       | `10 == 10`     |
| `!=`   | 不等于     | `10 != 5`      |
| `>`    | 大于       | `10 > 5`       |
| `<`    | 小于       | `10 < 5`       |
| `>=`   | 大于或等于 | `age >= 18`    |
| `<=`   | 小于或等于 | `score <= 100` |

## 逻辑运算符

逻辑运算符用于组合多个条件。

| 运算符 | 作用   | 说明                     |
| ------ | ------ | ------------------------ |
| `and`  | 逻辑与 | 两边都成立，结果才成立   |
| `or`   | 逻辑或 | 至少一边成立，结果就成立 |
| `not`  | 逻辑非 | 对结果取反               |

### 短路运算

`and`左边为假时，右边不再执行；`or`左边为真时，右边不再执行。

## 成员运算符

成员运算符用于判断某个数据是否存在于字符串、列表、元组等容器中。

| 运算符   | 作用           |
| -------- | -------------- |
| `in`     | 判断是否存在   |
| `not in` | 判断是否不存在 |

```python
fruits = ["苹果", "香蕉", "橙子"]

print("苹果" in fruits)       # True
print("西瓜" not in fruits)   # True
```

## 身份运算符

身份运算符用于判断两个变量是否指向同一个对象

| 运算符   | 作用               |
| -------- | ------------------ |
| `is`     | 是否为同一个对象   |
| `is not` | 是否不是同一个对象 |

```python
result = None

print(result is None)      # True
print(result is not None)  # False
```

### `==`和`is`的区别

- ==：比较两个对象的值是否相等
- 比较两个变量是否指向同一个对象

```python
a = [1, 2]
b = [1, 2]

print(a == b)  # True，内容相等
print(a is b)  # False，不是同一个列表
```

## 位运算符

位运算符直接对整数的二进制位进行运算

| 运算符 | 作用     |
| ------ | -------- | ------ |
| `&`    | 按位与   |
| `      | `        | 按位或 |
| `^`    | 按位异或 |
| `~`    | 按位取反 |
| `<<`   | 左移     |
| `>>`   | 右移     |

```python
print(5 & 3)  # 1


5 = 101
3 = 011
& = 001

# 所以结果是 1。
```

# 条件表达式

条件表达式可以根据条件选择不同的值。

```sh
条件成立时的值 if 条件 else 条件不成立时的值
```

```python
age = 20

result = "成年" if age >= 18 else "未成年"
print(result)  # 成年
```

# 常见问题

1、混淆赋值与比较

```python
# 错误
if age = 18:
    print("年龄是18岁")

#正确
if age == 18:
    print("年龄是18岁")
```

2、字符串不能直接与整数相加

```python
# 错误
age = 18
print("年龄：" + age)

# 正确
print("年龄：" + str(age))

# 或者使用f-string
print(f"年龄：{age}")
```

3、整除不能为0

```python
# 错误
print(10 / 0)  # ZeroDivisionError

# 正确
number = 0

if number != 0:
    print(10 / number)
```

4、小数点可能存在精度问题

```python
print(0.1 + 0.2)  # 0.30000000000000004
```
