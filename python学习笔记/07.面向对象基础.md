## 面向对象的两个基本概念-类与对象
- 类：用来描述具有相同的属性和方法的对象的集合。它定义了该集合中每个对象所共有的属性和方法。对象是类的实例。
- 对象：通过类定义的数据结构实例

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(f"我叫{self.name}，成绩是{self.score}分")


student1 = Student("小明", 80)
student2 = Student("小红", 95)

student1.introduce() # 我叫小明，成绩是80分
student2.introduce() # 我叫小红，成绩是95分
```

Student 是类，`student1` 和 student2 引用的是这个类创建的两个对象。

| 概念 | 含义 | 示例 |
| --- | --- | --- |
| 类（class） | 定义一类对象的数据和行为 | `Student` |
| 对象（object） | 根据类创建的具体对象 | `Student("小明", 80)` |
| 实例（instance） | 对象相对于其所属类的称呼 | 小明对象是 `Student` 的实例 |
| 属性（attribute） | 对象保存的数据或提供的名称 | `student1.name` |
| 方法（method） | 通过对象或类调用的相关功能 | `student1.introduce()` |

## 类与对象

类是对象的模板，我们得先有了类，才能制作出对象。

- 定义类的语法如下：
```python
class 类名:
    pass

# 创建对象
对象名 = 类名()
对象名.属性名1 = 属性值1
对象名.属性名2 = 属性值2
```

```python
# 定义类
class Car:
    pass

# 创建对象
c1 = Car()
c1.brand = 'BMW'
c1.name = 'X5'
c1.price = 500000 
```

## 类的定义

- 定义类的语法如下
```python
class 类名:
    def __init__(self, 参数列表):
        self.属性名 = 参数值

# 创建对象
对象名 = 类名(参数列表)
```

- `self`是方法的第一个参数,表示当前创建的实例对象
- `__init__`初始化方法，对象创建后自动调用，主要用于设置对象的初始状态(设置对象属性)

## 类的实例方法

- 语法如下
```python
class 类名:
    def __init__(self,形参列表):
        self.属性名 = 参数值

    def 方法名(self, 形参列表):
        ...
    ...

# 创建对象
对象 = 类名(参数列表)
对象名.方法名(实参)
```

## 魔法方法

- 魔法方法是指Python中提供的以双下划线开头和结尾的特殊方法,用于定义类的特殊行为，比如`__init__`.
- 魔法方法是不需要我们手动调用，Python会在合适的时机自动调用。

我们先看这个样一个例子:

```python
class Car:
    def __init__(self, color, name, price, speed):
        self.color = color
        self.name = name
        self.price = price
        self.speed = speed

c1 = Car('红色', 'BMW', 20000, '100码')
print(c1) # <__main__.Car object at 0x1039ff230>

c2 = Car('红色', 'BMW', 20000, '100码')
print(c2) #  <__main__.Car object at 0x103b3afd0>

print(c1 == c2) # False 实际比较是两个内存地址
print(c1 > c2) # TypeError: '>' not supported between instances of 'Car' and 'Car'

```

如果我们重写了魔法方法呢？

```python
class Car:
    def __init__(self, color, name, price, speed):
        self.color = color
        self.name = name
        self.price = price
        self.speed = speed

    def __str__(self):
        return f'{self.color} {self.name} {self.price} {self.speed}'
    def __eq__(self, other):
        return self.price == other.price and self.speed == other.speed and self.color == other.color and self.name == other.name
    def __lt__(self, other):
        return self.price < other.price

c1 = Car('红色', 'BMW', 20000, '100码')
print(c1) # 红色 BMW 20000 100码

c2 = Car('红色', 'BMW', 20000, '100码')
print(c2) # 红色 BMW 20000 100码

print(c1 == c2) # True
print(c1 > c2) # False
```

### 运算符相关的魔术方法

| 魔术方法 | 说明 |
| --- | --- |
| `__cmp__(self, other)` | Python 2 中的比较方法：返回负数表示 `self < other`，返回正数表示 `self > other`，返回 `0` 表示 `self == other`。Python 3 已移除，应使用以下比较方法 |
| `__eq__(self, other)` | 定义相等比较运算符 `==` 的行为 |
| `__ne__(self, other)` | 定义不等比较运算符 `!=` 的行为 |
| `__lt__(self, other)` | 定义小于比较运算符 `<` 的行为 |
| `__gt__(self, other)` | 定义大于比较运算符 `>` 的行为 |
| `__le__(self, other)` | 定义小于等于比较运算符 `<=` 的行为 |
| `__ge__(self, other)` | 定义大于等于比较运算符 `>=` 的行为 |

来看个简单的例子

```python
#!/usr/bin/env python3
# -*- coding: UTF-8 -*-

class Number(object):
    def __init__(self, value):
        self.value = value

    def __eq__(self, other):
        print('__eq__')
        return self.value == other.value

    def __ne__(self, other):
        print('__ne__')
        return self.value != other.value

    def __lt__(self, other):
        print('__lt__')
        return self.value < other.value

    def __gt__(self, other):
        print('__gt__')
        return self.value > other.value

    def __le__(self, other):
        print('__le__')
        return self.value <= other.value

    def __ge__(self, other):
        print('__ge__')
        return self.value >= other.value


if __name__ == '__main__':
    num1 = Number(2)
    num2 = Number(3)
    print(f'num1 == num2 ? --------> {num1 == num2} \n')
    print(f'num1 != num2 ? --------> {num1 == num2} \n')
    print(f'num1 < num2 ? --------> {num1 < num2} \n')
    print(f'num1 > num2 ? --------> {num1 > num2} \n')
    print(f'num1 <= num2 ? --------> {num1 <= num2} \n')
    print(f'num1 >= num2 ? --------> {num1 >= num2} \n')

```
输出的结果为：

```python
__eq__
num1 == num2 ? --------> False

__eq__
num1 != num2 ? --------> False

__lt__
num1 < num2 ? --------> True

__gt__
num1 > num2 ? --------> False

__le__
num1 <= num2 ? --------> True

__ge__
num1 >= num2 ? --------> False

```

## 实例属性和类属性

- 属性分为：
    - 实例属性：实例属性属于每个具体对象的属性，每个对象都是独立的。
    - 类属性：类属性是属于类本身的属性，所有实例共享的。

```python
class Car:
    wheel = 4 # 轮胎数量(类属性)
    tat_rate = 0.1 # 购置税(类属性)

    def __init__(self, name, price):
        self.name = name # 实例属性
        self.price = price # 实例属性

c1 = Car('BMW', 20000)
c2 = Car('BMW', 20000)
```

> 通过实例查找属性时，会先查找实例属性，实例属性不存在时，再查找类属性

### 类方法如何调用类属性

```python
class ClassA():
    var1 = '两点水'

    @classmethod
    def fun1(cls, age):
        print('我是 fun1' + cls.var1, '今年' +  str(age))


ClassA.fun1(18)
```
- 在方法上面，用 `@classmethod` 声明该方法是类方法。只有声明了是类方法，才能使用类属性
- 类方法想要使用类属性，在第一个参数中，需要写上 `cls` , `cls` 是 `class` 的缩写，其实意思就是把这个类作为参数，传给自己，这样就可以使用类属性了。
- 类属性的使用方式就是 `cls.变量名`
