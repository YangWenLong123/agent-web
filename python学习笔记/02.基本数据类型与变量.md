# 基本数据类型与变量

变量是用于保存数据的名称。Python不需要提前声明变量类型，直接赋值即可。

```python
name = "小明"
age = 18
score = 95.5
is_student = True
```

变量实际上是指向对象的名称：

```python
value = 10
print(type(value))  # <class 'int'>

value = "Python"
print(type(value))  # <class 'str'>
```

变量的命名规则： 
- 只能包含字母、数字和下划线。
- 不能以数字开头
- 不能使用Python关键字
- 区分大小写
- 推荐使用小写加下划线


## 基本数据类型

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| `int` | `18` | 整数 |
| `float` | `3.14` | 浮点数 |
| `complex` | `2 + 3j` | 复数 |
| `bool` | `True`、`False` | 布尔值 |
| `str` | `"Python"` | 字符串 |
| `list` | `[1, 2, 3]` | 列表，可修改 |
| `tuple` | `(1, 2, 3)` | 元组，通常不可修改 |
| `dict` | `{"name": "小明"}` | 字典，键值对集合 |
| `set` | `{1, 2, 3}` | 集合，元素不重复 |
| `NoneType` | `None` | 表示没有值 |
| `bytes` | `b"hello"` | 二进制数据 |

##  查看数据类型
```python
age = 18

print(type(age))              # <class 'int'>
print(isinstance(age, int))   # True
```

- `type()`:查看对象的实际类型
- `isinstance`：判断对象是否属于某种类型

## 类型转换

```python
age = int("18")
price = float("3.14")
text = str(100)
result = bool(1)

print(age)    # 18
print(price)  # 3.14
print(text)   # "100"
print(result) # True
```
