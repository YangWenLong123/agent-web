# Python初始

Python 是一种解释型、通用型编程语言。它的语法接近自然语言，代码量较少，既适合初学者入门，也广泛用于 Web 开发、数据分析、自动化脚本、人工智能和测试等场景。

本文先建立 Python 的整体认识，掌握运行代码和阅读基础语法所需的知识。变量、数据类型、运算符、函数等主题会在后续笔记中分别展开。

## 一、Python 的主要特点

- **语法简洁**：使用缩进表示代码块，不需要大量花括号和分号。
- **解释执行**：通常由 Python 解释器直接运行源代码，修改后可以快速验证。
- **动态类型**：变量不需要提前声明类型，类型由它当前引用的对象决定。
- **跨平台**：同一份代码通常可以在 Windows、macOS 和 Linux 上运行。
- **生态丰富**：可以通过标准库和第三方包完成网络请求、文件处理、Web 服务等工作。
- **强调可读性**：统一的代码风格有利于团队协作和后续维护。

## 二、准备 Python 环境

### 2.1 检查 Python 是否安装

在终端中执行：

```bash
python --version
```

如果系统中 `python` 指向其他程序，可以尝试：

```bash
python3 --version       # macOS / Linux 常用
py --version            # Windows 常用
```

建议使用 Python 3.12 或更高版本。看到类似 `Python 3.12.xxwxw` 的输出，说明解释器已经可以使用。

### 2.2 创建虚拟环境xw

每个项目建议使用独立的虚拟环境，避免不同项目的依赖互相影响：

```bash
python -m venv .venv
```

激活虚拟环境：

```bash
# macOS / Linux
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1
```

激活后，终端提示符通常会出现 `.venv`。退出环境：

```bash
deactivate
```

`.venv` 是本地环境目录，通常应加入 `.gitignore`，不提交到代码仓库。

## 三、运行 Python 代码

### 3.1 交互式解释器

直接在终端输入 `python`，可以进入交互式解释器（REPL）：

```text
>>> 1 + 2
3
>>> print("Hello, Python!")
Hello, Python!
>>> exit()
```

REPL 适合快速验证一个表达式或查询一个对象。较完整的程序应保存为 `.py` 文件。

### 3.2 运行脚本文件

新建 `hello.py`：

```python
print("Hello, Python!")
```

在文件所在目录执行：

```bash
python hello.py
```

也可以使用模块方式运行：

```bash
python -m hello
```

`-m` 会按照模块路径查找代码，项目较大时更容易保持导入路径一致。

### 3.3 一个程序是怎样执行的

可以把执行过程理解为：

```text
编写 .py 文件 -> Python 解释器读取代码 -> 执行语句 -> 输出结果或异常
```

Python 会按照代码的顺序执行语句。遇到函数定义时先创建函数，调用函数时才执行函数体。
